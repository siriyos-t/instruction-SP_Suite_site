ส่วนที่ 1

ติดตั้ง Tampermonkey และสคริปต์

ทำครั้งเดียวต่อเครื่อง ใช้เวลาราว 5 นาที ติ๊กแต่ละขั้นเมื่อทำเสร็จ หน้านี้จะจำไว้ให้

ความคืบหน้า

ยังไม่ได้เริ่ม
    1

    ติดตั้งส่วนขยาย Tampermonkey

    1. เปิด Tampermonkey ใน Chrome Web Store
    2. กด เพิ่มใน Chrome แล้วกด เพิ่มส่วนขยาย
    3. กดไอคอนจิ๊กซอว์มุมขวาบน แล้วกดหมุด Tampermonkey ให้ไอคอนโชว์บนแถบ
    1. เปิด Tampermonkey ใน Edge Add-ons
    2. กด รับ แล้วกด เพิ่มส่วนขยาย
    3. กดไอคอนจิ๊กซอว์ แล้วเปิดตา (แสดงในแถบเครื่องมือ) ให้ Tampermonkey
    2

    อนุญาตให้รันสคริปต์ของผู้ใช้

    เบราว์เซอร์รุ่นใหม่ต้องเปิดสิทธิ์นี้ก่อน ไม่อย่างนั้นสคริปต์ทั้งหมดจะไม่ทำงาน

    1. คลิกขวาที่ไอคอน Tampermonkey › จัดการส่วนขยาย (Manage extension)
    2. เปิดสวิตช์ อนุญาตสคริปต์ของผู้ใช้ (Allow User Scripts)
    3. ถ้าไม่เจอสวิตช์นี้ ให้ไปที่ chrome://extensions (Edge: edge://extensions) แล้วเปิด โหมดนักพัฒนาซอฟต์แวร์ มุมขวาบนแทน
    3

    ปิดสคริปต์ตัวเก่า (ถ้าเคยติดตั้ง)

    SP Suite รวมสคริปต์เดิม 9 ตัวไว้แล้ว ถ้าเปิดพร้อมกันจะทำงานซ้อนกัน

    1. กดไอคอน Tampermonkey › แดชบอร์ด
    2. ปิดสวิตช์สคริปต์ที่ชื่อขึ้นต้นด้วย Bplus -, Bplus AI - และ BPlus QA Repair Tool
    ไม่เคยติดตั้งสคริปต์เดิม ข้ามขั้นนี้ได้เลย ติ๊กว่าทำแล้วได้
    4

    ติดตั้ง SP Suite

    กดปุ่มด้านล่าง Tampermonkey จะเปิดหน้าติดตั้งขึ้นมาเอง แล้วกด ติดตั้ง (Install)

    ติดตั้ง SP Suite v2.1.1
    ถ้ากดแล้วเห็นเป็นหน้าโค้ดยาว ๆ แทนหน้าติดตั้ง แปลว่าขั้นที่ 1–2 ยังไม่เรียบร้อย กลับไปเช็คสวิตช์ อนุญาตสคริปต์ของผู้ใช้ แล้วกดปุ่มอีกครั้ง
    5

    เปิด cloudbplusai แล้วเลือกแผนก

    1. เปิด cloudbplusai.bplus.co.th แล้วล็อกอินตามปกติ (ถ้าเปิดอยู่แล้ว กด F5 รีเฟรช)
    2. หน้าตั้งค่าจะเด้งขึ้นเองครั้งแรก เลือกแผนก ERP, HRM หรือ SE
    3. เลือกบทบาท หัวหน้า หรือ เจ้าหน้าที่ ระบบจะเปิด/ซ่อนเครื่องมือให้เหมาะกับงาน
    4. มุมล่างขวาของหน้าตั้งค่าจะบอกเวอร์ชัน ต้องตรงกับปุ่มติดตั้งด้านบน
    อัปเดตเวอร์ชันใหม่: กลับมาหน้านี้แล้วกดปุ่ม "ติดตั้ง SP Suite" อีกครั้ง Tampermonkey จะขึ้นปุ่ม อัปเดต (Update) ให้ ค่าที่ตั้งไว้ยังอยู่ครบ
    ส่วนที่ 2

    เครื่องมือทั้งหมด

    เลือกบทบาทของคุณ หน้านี้จะโชว์เฉพาะเครื่องมือที่คุณใช้ ทุกเครื่องมือเปิดได้จากแถบด้านบนของเว็บ ไม่ว่าจะอยู่หน้าไหน

    แสดงเครื่องมือทั้ง 8 กลุ่ม

    QA Repair

    Helpdesk
    ปุ่ม QA Repair บนแถบ · ใช้คู่กับหน้าแก้ไขบทความ
    • นำเข้าบทความจากไฟล์ .md แล้วกรอกฟอร์มบทความให้อัตโนมัติ ทั้งชื่อ คำอธิบาย เนื้อหา Keywords และคำถาม
    • ตรวจไฟล์ก่อนซ่อมตามเกณฑ์ 15/15: คำถาม 25 ข้อ, Keywords 25 คำ, คำอธิบาย 20–120 ตัวอักษร, เนื้อหาอย่างน้อย 2,000 ตัวอักษร
    • ดาวน์โหลด ไฟล์ตัวอย่าง และ คำสั่งสร้าง Skill ไปให้ AI ช่วยเขียนไฟล์ .md ได้
    วิธีใช้
    1. เปิดหน้าแก้ไขบทความในเว็บ
    2. กด QA Repair › เลือกไฟล์ .md › เลือกข้อที่จะซ่อม
    3. ดูป้าย ✓/✗ ใต้พรีวิว ถ้ามี ✗ ให้แก้ไฟล์ก่อนจะดีที่สุด
    4. ติ๊กส่วนที่จะจัดการ แล้วกด ซ่อมอัตโนมัติ (ล้าง → รอ 1 วินาที → กรอกใหม่)
    5. ตรวจหน้าฟอร์มอีกรอบ แล้วกดบันทึกของเว็บเอง

    งานของฉัน

    ทุกคน
    อยู่ในหน้า QA Repair · แจ้งเตือนเด้งมุมซ้ายล่าง
    • เตือนเมื่อมี Action Items ที่มอบหมายให้คุณ พร้อมปุ่มพาไปหน้ารายการแล้วเลือกชื่อคุณให้
    • คัดลอกตาราง Excel สรุปงานที่คุณปิดวันนี้ (ลำดับ / รหัส / เหตุผล / บันทึก / ลิงก์บทความ)
    • คิวที่ฉันรับช่วงค้างอยู่ พร้อมปุ่มคืน Bot ทั้งหมดของฉันในคลิกเดียว
    วิธีใช้
    1. กด เปิดแจ้งเตือน Windows ครั้งแรก แล้วกดอนุญาต จะได้เตือนแม้ไม่ได้ดูหน้าเว็บ
    2. ระบบตรวจงานให้เองทุก 2 นาที กด ตรวจงานเดี๋ยวนี้ ได้ตลอด
    3. ก่อนเลิกงาน กด คัดลอกตาราง Excel แล้ววางในไฟล์รายงาน
    4. ตั้งแต่ 17:00 ถ้ายังมีคิวที่รับช่วงค้าง การ์ดสีส้มจะเด้งเตือนทุก 30 นาที กด คืน Bot ทั้งหมด ได้จากการ์ดเลย

    ตัวช่วยบนหน้าคิว Handoff และประวัติลูกค้า

    ทุกคน
    ไม่ต้องกดเปิด ทำงานเองบนหน้าเว็บ · ทุกปุ่มที่เพิ่มเข้าไปมีป้าย SPตัวอย่าง ให้รู้ว่ามาจาก SP Suite
    • ดึงชื่อไลน์ & บริษัท — ปุ่มข้างแท็บคิว แสดงชื่อลูกค้าและบริษัทใต้การ์ดคิว (ดึงทีละ 20 คิวล่าสุด)
    • ช่องค้นหาคิว — พิมพ์ชื่อ นามสกุล บริษัท หรือรหัส Session เพื่อกรองการ์ดทันที
    • เรียงคิวตามเวลาแชทล่าสุด — พร้อมป้าย "อัปเดตล่าสุด" สีส้มใต้การ์ด และดึงลึกถึง 1,000 คิว
    • ล็อกคิวตามแผนก — เลือกสินค้าของแผนกในดรอปดาวน์ให้อัตโนมัติ
    • กันเด้งเข้าจอเดี่ยว และ กันแชทเด้งลงล่างสุด ระหว่างอ่านข้อความเก่า
    • แก้ไขโปรไฟล์ลูกค้า — ปุ่มแดงข้างรหัส Session เปิดหน้าประวัติลูกค้า ค้นหาชื่อ แล้วกดแก้ไขให้
    • เติมข้อมูลเริ่มต้น — ปุ่มน้ำเงินในหน้าต่างแก้ไขลูกค้า เติมตำแหน่ง เบอร์ อีเมล บทบาท หมายเหตุ ตามค่าของแผนก

    สรุป SLA

    หัวหน้า
    ปุ่ม สรุป SLA บนแถบ · ใช้ได้ทุกหน้า
    • สรุปคิว LINE รายวันหรือรายเดือน แยกสินค้า ERP / POS / HRM
    • คิวทั้งหมด · บอทตอบจบเอง · เจ้าหน้าที่รับช่วง · คำถามที่บอทตอบไม่ได้ · Action Items ของทีม
    • บันทึกเป็นภาพ PNG ความคมชัดสูงสำหรับส่งสรุปงานสิ้นวัน และส่งออก CSV
    • ตารางเจาะลึกด้านล่างไว้พิสูจน์ที่มาของตัวเลขทุกตัว
    วิธีใช้
    1. กด สรุป SLA › เลือก รายวัน หรือ รายเดือน และวันที่
    2. สินค้าถูกเลือกตามแผนกให้แล้ว เปลี่ยนได้จากดรอปดาวน์
    3. กด ดึงข้อมูล รอสักครู่
    4. กด บันทึก PNG แล้วส่งภาพเข้ากลุ่ม LINE

    Overdue

    หัวหน้า
    ปุ่ม Overdue บนแถบ · ตัวเลขบนปุ่ม = งานเกินกำหนดของแผนก
    • รวม Action Items ที่เกินกำหนด จัดกลุ่มตามคน เรียงจากค้างมากไปน้อย
    • สีบอกความหนัก: เหลือง ≤ 2 วัน · ส้ม ≤ 7 วัน · แดง เกิน 7 วัน
    • คัดลอกข้อความสรุปส่งกลุ่ม LINE หรือข้อความทักรายคนพร้อมรายการงาน
    วิธีใช้
    1. กด Overdue › เลือกแท็บแผนก (ตั้งค่าเริ่มต้นเป็นแผนกของคุณ)
    2. ติ๊ก เฉพาะทีม Support ไว้ เพื่อซ่อนงานของ RD
    3. กด คัดลอกสรุปส่ง LINE แล้ววางในกลุ่ม
    4. ทักรายคน: กดไอคอนแชทท้ายชื่อ · ดูงานในเว็บ: กดไอคอนแว่นขยาย

    คืน BOT

    หัวหน้า
    ปุ่ม คืน BOT บนแถบ · ใช้สิ้นวัน และก่อนเริ่มงานเช้าให้ Bot ทำงานเต็มที่
    • กรองคิวตาม Product ช่วงวันที่ คำค้นหา และสถานะ (รอรับช่วง / เจ้าหน้าที่ตอบ / ทั้งสอง)
    • พรีวิวในตารางก่อน ติ๊กเลือกเฉพาะคิวที่ต้องการ แล้วค่อยกดยืนยัน
    • คืนทีละ 5 คิวพร้อมกัน มีแถบความคืบหน้า และกดหยุดกลางทางได้
    วิธีใช้
    1. กด คืน BOT › ตรวจ Product (เลือกตามแผนกให้แล้ว) และช่วงวันที่
    2. เลือกสถานะคิว แล้วกด ค้นหาและดูพรีวิว
    3. เอาติ๊กออกจากคิวที่ยังคุยกับลูกค้าอยู่
    4. กด ยืนยันคืน Bot แล้วกดตกลงในหน้าต่างยืนยัน
    ระหว่างกำลังคืน ถ้าปิดหน้าต่าง ระบบจะถามก่อน และหยุดคิวที่เหลือให้

    การตั้งค่า

    กดไอคอนตั้งค่าบนแถบ ทุกค่าบันทึกทันทีในเบราว์เซอร์เครื่องนั้น ไม่ต้องกดบันทึก

    แผนกกำหนดค่าเริ่มต้นให้ทุกเครื่องมือ

    กดเลือกแผนกเพื่อดูค่าที่ระบบตั้งให้

    แก้ได้ทุกค่าที่ ตั้งค่า › ข้อ 5 · กด คืนค่าแผนก เพื่อกลับเป็นค่าตั้งต้น

    บทบาท

    • หัวหน้า — เปิดทุกเครื่องมือ
    • เจ้าหน้าที่ — ซ่อน สรุป SLA, Overdue และ คืน BOT ให้แถบโล่ง (เปิดคืนรายตัวได้ในข้อ 3)

    ธีมและตำแหน่ง

    • ธีม สว่าง / มืด — สลับเร็วด้วยไอคอนพระจันทร์/พระอาทิตย์บนแถบ
    • สีประจำแผนก หรือเลือกเองจาก 6 สี / กำหนดสีเอง
    • แถบฝังใน header หรือลอยมุมล่างขวา

    อื่น ๆ

    • เปิด/ปิดเครื่องมือและตัวช่วยบนหน้าเว็บได้ทีละตัว มีผลทันที
    • เวลาเริ่มเตือนคืน Bot ของฉัน (ค่าเริ่มต้น 17:00) มีปุ่ม ทดลองเตือน
    • ซ่อนปุ่มลอยของสคริปต์เดิม เผื่อยังไม่ได้ปิดตัวเก่า

    แก้ปัญหาที่พบบ่อย

    ไม่เห็นแถบ SP บนหัวเว็บ
    1. กดไอคอน Tampermonkey บนหน้า cloudbplusai ต้องเห็น Bplus SP Suite และสวิตช์เปิดอยู่
    2. ถ้าไม่มีชื่อสคริปต์ขึ้นเลย ให้เช็คสวิตช์ อนุญาตสคริปต์ของผู้ใช้ ในขั้นที่ 2
    3. กด Ctrl + F5 รีเฟรชหน้าเว็บ
    4. จอแคบ แถบอาจถูกย่อ ลองเปลี่ยนเป็น "ลอยมุมล่างขวา" ในตั้งค่า
